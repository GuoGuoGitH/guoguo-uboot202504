# U-Boot v2025.04 — Source Reference

A personal study and reference checkout of **U-Boot v2025.04**.

This repository preserves an upstream source baseline and commit history for reading, debugging, and comparing U-Boot internals across releases.

## Research areas

- Boot flow and early platform initialization
- Device Tree (FDT) and Driver Model (DM)
- Board configuration and embedded firmware architecture
- Source navigation and version-to-version comparisons
